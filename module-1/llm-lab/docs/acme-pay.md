# Acme Pay API — внутренняя памятка

- Базовый адрес: https://api.acmepay.example/v3
- Лимит запросов: 120 в минуту на один ключ. При превышении возвращается код 429.
- Возврат платежа возможен в течение 45 дней после оплаты.
- Webhook повторяется до 6 раз с нарастающей паузой, затем событие помечается как failed.
- Ключи ротируются раз в 90 дней.
