# module-1/token-lab

Материалы для модуля 9 «Оптимизация токенов». Работа идёт в **чате Claude Code в вашей IDE**. Встроенный терминал IDE нужен только для коротких команд `node ../lab.js …` (сброс и подготовка файлов) и для запуска тестов. Нужен Node.js.

Пошаговая инструкция — в модуле 1 (`module1.html#m9`).

## Что внутри
| Путь | Назначение |
|---|---|
| `sample-app/` | Мини-проект на JS с одним багом (процентный купон) и «шумом»: `docs/`, `legacy/`, `logs/`. **Именно эту папку открывайте в IDE как рабочую.** |
| `prompts/` | Готовые промпты для каждого шага (имя файла = номер строки в таблице) |
| `rules/` | Раздутый и короткий `CLAUDE.md` |
| `settings/` | Запрет на чтение «шума» |
| `lab.js` | Помощник: `reset`, `rules-bloated`, `rules-lean`, `deny`, `status`, `check` |
| `_pristine/` | Эталонная копия `sample-app` для `reset`. Не открывайте и не меняйте |
| `results.md` | **Файл с вашими результатами — его вы отправляете на проверку** |

## Команды (из папки `sample-app`)
```bash
node ../lab.js reset          # вернуть проект в исходное состояние
node ../lab.js rules-bloated  # положить раздутый CLAUDE.md
node ../lab.js rules-lean     # положить короткий CLAUDE.md
node ../lab.js deny           # положить запрет на чтение docs/legacy/logs
node ../lab.js status         # что сейчас настроено
node ../lab.js check          # проверить results.md перед отправкой
```
